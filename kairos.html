The MethodHow it was run

Elevated minimalism — Aesop meets a Tokyo stationery brand.

Built as a full Shopify Online Store 2.0 theme — every tool operating under a written system. The colour law, the figure library as the only permitted illustration source, exact-asset reuse: the constitution is written first, the tools execute against a locked spec. What follows is what that system rejected.
