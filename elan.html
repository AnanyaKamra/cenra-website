The MethodHow it was run

Editorial architecture portfolio — asymmetry, air, and a thin rule.

Built as an editorial portfolio rather than a services site: a fixed identity column against scrolling project content, strong asymmetry, generous negative space, and photography allowed to run large. Three families, never more — Cormorant Garamond for statement, Inter for everything functional, JetBrains Mono for the small editorial marks that number a project or name a place. Terracotta holds at two per cent. Corners stop at four pixels. Motion is a three per cent hover and a seven-hundred-millisecond ease — calm enough to be nearly imperceptible.

OutcomeWhat it shows

A studio that reads as restraint, not display.

  • 01

    Positioning — locked. Quiet luxury via Indian craftsmanship, without a single word of luxury cliché.

  • 02

    Verbal identity — a vocabulary with an explicit do-not-use list. The words a studio refuses are as defining as the ones it keeps.

  • 03

    Website — an editorial portfolio where photography carries the argument and type stays out of its way.

  • 04

    System — three typefaces, six colours, four-pixel corners. Constrained enough that every future page composes itself.
